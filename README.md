# Gens OP

Gens OP is a comprehensive Minecraft plugin designed for Paper/Spigot 1.21.11 servers, offering a complete "Gens OP / Generator Network" experience. This plugin includes a lightweight and efficient generators system, automatic island creation, a modern scoreboard, an integrated economy, and a player shop system. It is optimized to run smoothly on servers with a RAM limit of 3.5GB, ensuring minimal lag.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/GensOP/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. **Generators System**:
   - Place generator blocks to start producing resources.
   - Upgrade generators to higher levels to produce more valuable resources.
   - Withdraw resources with a single click or merge similar generators to reduce clutter.
   - All generator data is automatically saved.

2. **Islands & Claiming System**:
   - Use the `/island` command to create and manage your island.
   - Teleport to your island using `/is` or `/island`.
   - Protect your island from unauthorized access with the trust/invite system.

3. **Scoreboard & HUD**:
   - A modern and fast-updating scoreboard will display your player name, rank, balance, generator level, and server information.

4. **Economy & Shops**:
   - Use the `/shop` command to buy and sell resources.
   - Quickly sell all items in your inventory using `/sellall`.
   - Create and manage player shops to buy and sell resources among players.

5. **Ranks & Rewards**:
   - Use the `/rank` command to check your rank and claim rewards.
